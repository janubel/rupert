Phase 0

Now · reliable SQLite operations

Ship the feature catalog, planner maintenance and conservative worker concurrency. Reconcile production documentation.

Ready when

Both adapter CI jobs pass; authenticated catalog renders; diagnostics contain no customer data; Pages links and mobile layout verified.

Phase 1

Next · inventory execution

Complete native stock coverage and exact location/identity count comparisons; extend reviewed gram recipes, lot consumption, exception review, scanner counts and reservations. Then add material/Sheets reconciliation, transfers and backorders. Payment and terminal execution have separate acceptance gates.

Ready when

Tenant/role isolation, exact source identities, completeness, replay and concurrent stock/mapping tests pass; counts use one verified source/location pool. Overlap commissions award 1% independently to each worker. Primary POS requires demonstrated taxes, tender/tip/refund/settlement, hardware and operator acceptance before cutover.

Phase 2

Then · fulfillment and channels

Returns/exchanges, carrier labels, lot/serial traceability and marketplace listing adapters.

Ready when

Sandbox round trips cover partial fulfillment, cancellation, duplicate events and failed payments; no automatic equalization of independent inventories.

Phase 3

Then · trusted financial operations

Double-entry ledger, reconciliation, open books, forecasts, profit sharing and payroll exports.

Ready when

Trial balance balances, closed periods reject edits, source-to-report totals reconcile, compensation permissions pass and provider exports reconcile.

Phase 4

Later · broader ERP

Manufacturing, CRM/marketing, public integrations, offline mobile work and multi-company reporting.

Ready when

Each module has an owner, data contract, migration, tenant/security tests, operational runbook and a measured capacity check before release.
