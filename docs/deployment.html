Deployment

Rupert is currently hosted at rupert.stoverparc.org. The current production host is SER8 in an Incus instance.

Release and deployment

GitHub Actions runs CI and creates a GitHub release from a version tag. There is no automated production deploy configured in this repository. A release does not update the live instance.

Use the SER8-specific worker and backup units plus the host freshness watcher under deploy/. Older droplet units are reference material. Confirm active services before promotion.

Database

The October 13, 2026 cutover report records production on SQLite with FTS5 search. The live instance and release 11af6b8 were verified on October 14; see the deployment receipt. See SQLite and Incus operations for tuning, recovery and scaling decisions.

Backups

The cutover report records six-hourly local SQLite snapshots and settings/env backups. Verify off-host encrypted copies and a restore drill; local snapshots alone cannot recover from host loss.

Continuous integration

CI runs in the official ruby:4.0 container against PostgreSQL and SQLite: RuboCop, migrations, Tailwind build, asset precompile, and the full test suite. Every push or pull request triggers it.
